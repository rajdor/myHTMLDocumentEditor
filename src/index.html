Formatting here

    Listed from the outside in. Clear format removes all text formatting at once.
    Help

    {{ic:text-aa}}Writing and styles
    • Type in the page. Hover over any button to see what it does.
    • Pick a style from the Style list: H1 is the title, H2 to H4 are heading levels. A style picked over several lines goes on each of them, and list items in the selection leave their list. Code block over several lines makes one code block with a line for each; another style on a code block gives a line for each of its lines.
    • Print (Ctrl+P) prints the whole document without the toolbar and panels.
    • Divider puts a horizontal line across the page where the cursor is. Click at the end of the line before it and press Delete to remove it.
    • The More list has superscript, subscript, strike-through and inline code: select text and choose one to switch it on or off. A tick marks the ones that are on at the cursor.
    • Indent and Outdent, or Tab and Shift+Tab, move list items in or out a level. Outdent at the top level turns the item into a paragraph. The first item of a list has nothing above it to go under, so it cannot be indented.
    • Link opens a small form for the display text and the address. The display text starts as the selected text; the address starts as the selected text when that is a web address, or as the clipboard when it holds one and the browser already allows this page to read it.
    • A Q&A answer can hold a list: with the cursor on a line of the answer, press a list button. Enter on an empty item, or the same list button again, goes back to plain answer text. Questions cannot hold lists.
    • Emoji opens a small list of emoji; click one to put it in where the cursor is. A saved document holds each one as an HTML code. The reader's own computer draws it, so it can look a little different on Windows and on a Mac.
    • Inspect formatting (the magnifying glass) shows what formatting is on the text at the cursor or the selected word, marks anything the toolbar cannot make there, and can remove one format at a time.
    • Box: the Box list inserts a Note, Information, Tip, Warning or Critical box for the reader after the current block. Type or paste into it; what goes in keeps its own style. With text selected, the list puts the selected blocks in the new box instead, each one whole. The label can be retyped. With the cursor in a box, the list changes its type, and Hide icon leaves the coloured box and its label without the icon. Enter on an empty last line leaves the box; Remove box takes it away and keeps the content.
    • Compact list, beside the list buttons, puts less space between the lines of the list the cursor is in; press it again to go back.
    • Start numbering at, beside it, sets the first number of the numbered list the cursor is in, so a list can carry on from an earlier one. The form offers the next number; once set it stays until you change it.
    • Checklist: the Checklist button makes a list with tick boxes. Click a box to tick it; ticks made here are saved with the document. In a saved document the boxes can still be ticked, but those ticks are not kept.
    • Each title or H2 can have a subtitle. H2 headings number themselves.
    • Repeat last toolbar command: Option+Q on a Mac or Alt+Q on Windows applies the last toolbar command again at the cursor or on the selection. Holding Option or Alt while you click or drag does the same in one move. The Repeat button beside Redo names the command. It covers the Style list, bold, italic, bulleted, numbered and Q&A lists, code block, ID tag, Note, Clear format and the table buttons. Bold, italic, lists and Compact are set, not toggled.
    • Copy format copies a look from one place to another: put the cursor in the source text and press the button, then click a block to give it the block style, or select text to give it bold, italics and the ID tag as well. Double-click the button to keep it on; Esc ends. Links, list type and table settings are not copied.
    • Clear format removes bold and italics from the selected text only. With the cursor only, or with a whole block selected, it clears the whole block and turns a heading, styled paragraph or code block into a plain paragraph. Links and ID tags are never removed; tables, lists and diagrams stay.
    {{ic:tree-view}}Index
    • The index lists H2 headings.
    • Click Show Index Levels on the toolbar to step through 1, 2 and 3 levels; 2 and 3 add H3 and H4. The small number on the button is the current level.
    • The choice is saved with the document. New documents start at 1 level.
    {{ic:clipboard-text}}Copy, cut and paste
    • Copy, cut and paste keep formatting.
    • Copied in the editor: bold, italics, links, ID tags, headings, lists, tables, code and diagrams paste as they were.
    • From other programs: structure is kept (headings, lists, tables, bold, italics, links) and takes this document's style.
    • In a table cell, pasted text stays in the cell. In a code block, paste is plain text.
    • Cells copied from a table, here or in a spreadsheet, and pasted with the cursor in a table go in cell for cell from that cell, across and down. If cells in the way hold something, or the table has too few rows or columns, it says so and asks first.
    {{ic:table}}Tables
    • To select a column, a row or a block of cells: click a cell, then Shift+click another, or drag from one cell into another. Bold, Italic, Clear format, the header and merge buttons, Delete, copy and cut then act on those cells. Esc or a click ends it.
    • Drag the border between two columns to resize them; the table keeps its width. Double-click a border to go back to automatic widths.
    • Header row, Sub header row, Header column and Sub header column set the whole row or column the cursor is in, or every one in the selection. The same button again makes it ordinary. Any row can be changed, including the top one.
    • Enter and Shift+Enter start a new line in the same cell.
    • Tab at the end of a line moves to the next cell in the row (nothing at the row end); elsewhere in a cell it inserts a tab space. Shift+Tab moves to the previous cell.
    • Down and Up on the last or first line of a cell move to the cell below or above.
    • The add buttons put a row above or below, or a column left or right, of the cell under the cursor.
    • The merge buttons join a cell with its neighbour; select across several cells first to merge them all. Split undoes a merge, or splits a single cell into two.
    • Table format opens a bar under the toolbar that stays open while you work. Cell colour is for the cell the cursor is in, or the selected cells: pick a colour, or type one under Custom and press OK. Spacing, Padding, Borders and Corners are for the whole table. Rounded corners need spacing, so Rounded turns Small spacing on. In a table with spacing, a cell with no text and no colour draws nothing on the saved page.
    • For a short label in a rounded tag, select the words and choose Pill in the More list; Pill at right puts it at the right-hand edge of its line.
    • The row, column, merge, split and compact buttons work on the cell under the cursor and are dimmed outside a table.
    {{ic:link}}Links
    • Link adds a link to the selection, or edits the link under the cursor. Clear the address to remove it.
    • Click a link to place the cursor in it. Ctrl or Cmd + click opens it.
    • Images, video and audio from the web are shown as link cards and never downloaded.
    • Links look as the browser shows them: the surrounding font, blue and underlined.
    {{ic:note-pencil}}Notes
    • Select one or more blocks (or put the cursor in one, or select a diagram) and press Note. The notes margin opens with a bar beside the blocks and a note icon.
    • The log opens with today's date and your initials. Everything in the log can be edited, the date too.
    • Note again on a date the log already has adds a line under it. Selecting into a note grows it.
    • Click the icon to open or close a log; Esc or clicking elsewhere closes it. Logs are always closed when a document opens.
    • Delete all of a note's comments and it goes, leaving the blocks.
    • The Notes margin button, beside Note, hides or shows the margin. It starts hidden; a yellow dot on the button means the document has notes that are not shown. The choice is saved with the document.
    • After Save, you can also save a clean copy without notes.
    • Click the person icon at the right of the toolbar to set or change your initials. The icon is filled once they are set.
    {{ic:code-block}}Code
    • Enter starts a new line and Tab inserts a tab.
    • Enter on an empty last line leaves the block.
    {{ic:chats-circle}}Q&A
    • In a question, Enter moves to its answer.
    • In an answer, Enter starts a new line; Enter on an empty last line starts the next question.
    • Enter on an empty question ends the list.
    • Any paragraph can be turned into a question or answer from the Style list.
    {{ic:shapes}}Diagrams
    • Diagram draws a new diagram in the built-in diagram editor; press Done there to place it in the document.
    • Double-click a diagram, or select it and press Enter, to edit it again.
    • Data model opens Data Model Studio: build the model guided by questions or on your own (Fly solo), then press Done to place its picture. The model itself is kept with the picture, so double-clicking it opens the full model again, every tab included.
    • To bring in a diagram written as draw.io XML, such as an answer from an AI assistant: copy the XML, press Diagram, then choose Edit, Paste from draw.io XML (clipboard) in the diagram editor and press Done.
    • Pictures and Mermaid from other pages: click a picture drawn with shapes and lines, or put the cursor in a Mermaid flowchart definition, and press Convert to editable diagram (or double-click the picture). It opens in the diagram editor as shapes, lines and text you can change; Done puts the diagram in its place and Cancel leaves the page as it was. A picture with no boxes, diamonds or ellipses, a photo or screenshot, and Mermaid diagrams other than flowcharts cannot be converted and stay as they are.
    • Diagrams drawn with HTML boxes: when a page from elsewhere holds a diagram made of boxes set out by its style sheet (a layer or architecture picture), each such diagram is made into an editable diagram as the page opens, and a line under the toolbar says how many. An arrow written as a character between two boxes becomes a connector.
    • Older diagrams drawn directly on the page open the same way: they are converted for the diagram editor, and Done replaces them with the new diagram.
    • Drag to move (snaps to the 8px grid; hold Alt to move freely). Drag the blue corner to resize.
    • Double-click or press Enter to edit text; Enter adds a line, Esc finishes.
    • Arrow keys nudge by 8px, Shift+arrow by 1px. Delete removes. Ctrl+D duplicates. Ctrl+Z undoes diagram changes.
    {{ic:line-segments}}Connectors
    • Press Connect, click the source, then the target.
    • Connectors re-route when shapes move.
    • Click a connector to set its sides, line type, arrowhead and verb.
    {{ic:bounding-box}}Show blocks
    • A page from elsewhere keeps its layout containers but not the style sheet that set them out, so parts of it can sit oddly. Show blocks marks each kind of block in its own way: a container is outlined in dashed amber with a light tint and labelled with its tag and class; a table has a solid purple outline and a table tab; a paragraph, heading, list or code block has a small grey tag in the left margin and no outline.
    • Click in a container, or on its edge, to choose it. Unwrap container takes the container away and keeps what is in it; Delete container takes both.
    • Delete empty containers clears every container with nothing in it, so you can move or copy the content out and then clear what is left.
    • Containers are shown with a little space inside them so that nested ones can be told apart. The view is not saved with the document.
    {{nb:help}}
    {{ic:floppy-disk}}Files
    • Save writes one self-contained HTML document that opens in any browser and re-opens here.
    • After a save, a line shows the name of the file saved. The browser tells the editor the file name only, not the folder.
    • A dot on the Save button means there are unsaved changes.
    • New and Open ask first when there are unsaved changes.
